## What I'm working on

Training robot arms to handle tasks that scripted code can't using either RL, imitation learning, or real-time perception to close the loop between sensing and action.

---

## Select Projects
**6DoF Pose Estimation driving a Robot Arm**
Used NVIDIA FoundationPose + Intel RealSense D405 to estimate object pose in real time and feed it into a velocity controller on a Ufactory arm, no predefined waypoints.

**Quadruped Locomotion with RL (Unitree Go2)**
Built a full RL pipeline from scratch in Isaac Lab: reward design, terrain-aware observations, domain randomization. Progressed from flat-ground walking to stair climbing. [Watch on YouTube](https://www.youtube.com/watch?v=QsNKTH_Yu4U)

**Slip-Aware Robot Arm Manipulation (Nature Communications)**
Co-authored research on detecting and correcting linear and rotational slip during robotic grasping. Contributed to control algorithms and physical experiments on real robot arms.
